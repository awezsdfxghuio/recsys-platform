# Платформа хранения, аналитической обработки данных и рекомендательных систем

Комплексный проект, демонстрирующий стек технологий работы с большими данными: от распределенного хранения до построения рекомендательной модели машинного обучения.

## Архитектура проекта

Проект разделен на три взаимосвязанных модуля:

1. **Распределенные системы хранения данных (РСХД):**
   - Развернут 4-узловой кластер распределенного объектного хранилища **SeaweedFS** в Docker.
   - Реализована топология с разделением метаданных (Master Node) и узлов хранения данных (Volume Nodes).
   - Настроена синхронная репликация данных (фактор 2x, `replication: 001`).
   - Реализован механизм автоматического переключения при отказе узла (Failover).

2. **Технология хранения и обработки данных (ТХОД / ETL):**
   - Пакетная обработка сырых логов пользовательских оценок (датасет MovieLens, 100k событий).
   - Трансформация временных меток, реляционное объединение таблиц (JOIN).
   - Формирование аналитической витрины (Data Mart) с фильтрацией статистически надежных сущностей.

3. **Прикладные задачи анализа данных (RecSys):**
   - Построение системы коллаборативной фильтрации на базе сингулярного разложения матриц (**SVD**).
   - Оценка качества предсказания по метрике **RMSE** против модели смещений Белла-Корена (**Baseline**).
   - Реализация инференса персональной выдачи Top-5 рекомендаций для конкретного пользователя.

## Инструкция по запуску

1. **Запуск распределенного кластера СХД:**
   ```bash
   docker compose up -d
   ```

2. **Установка зависимостей Python:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Запуск веб-платформы:**
   ```bash
   streamlit run app.py
   ```
